移除目录只停止扫描，不删除文件或已登记引用；点击 Apply 或保存以保留变更。同名本地技能按 SKILL.md 修改时间保留最新来源。

来源目录与扫描结果
已登记的原生技能引用

登记来源引用，不复制技能正文。输入 /skill 或 /skill 关键词选择已登记引用，仅交给适用 CLI 使用。登记只影响显式候选，原生自动调用仍按原生规则与设置；移除引用不会禁用原生技能。来源不可用时会提示。

会话记录由 Chorus 保存，每次调用补充最近历史。支持临时会话的 Agent 优先使用临时会话；其他 Agent 按原生设置保存记录，Codex 目标会话也会保存在原生历史中。服务商的数据保留政策仍适用。
