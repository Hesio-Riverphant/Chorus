# Chorus application icon

The project owner supplied the original application icon and authorizes its distribution with Chorus under the repository's MIT license. It is cropped and scaled into `convoke.png` and the seven sizes in `convoke.ico`. The original source path is not distributed.

Windows packaging embeds and reads back every icon resource using `scripts/set-windows-icon.ps1`. The Electron window and in-app brand use the PNG. Provider icons retain their separate license.
